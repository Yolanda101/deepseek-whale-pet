# DeepSeek 大肥鱼 · 手办版

将 `deepseek-q-whale` 文件夹放入 Codex 的本地 `pets` 目录。macOS 默认位置是 `~/.codex/pets/`。打开 Codex 设置中的宠物页，刷新列表，选择「DeepSeek 大肥鱼 · 手办版」。`pet.json` 和 `spritesheet.webp` 应直接位于 `deepseek-q-whale` 文件夹里。

十种互动已画进这张手办外观。Codex 根据光标、拖动和任务状态播放对应片段。每行沿用当前桌面版自带的格数和速度。

| 在 Codex 中 | 大肥鱼会做什么 |
|---|---|
| 待机 | 站立眨眼，尾鳍抬起再向另一侧甩过去 |
| 首次唤醒 | 挥手打招呼，然后歪头托腮撒娇 |
| 鼠标移到她身上 | 踏出舞步，转身跃起，举起草帽想出门玩，再落地 |
| 任务失败 | 气鼓鼓地用尾巴抽向镜头，随后掉眼泪、擦泪 |
| 等待确认 | 捧空碗讨饭，获得食物后用勺子吃饭 |
| 检查结果 | 翻书核对，累得头晕坐倒，再睁眼缓过来 |
| 任务运行、左右拖动 | 使用笔记本工作，或面朝拖动方向迈步 |

移动光标还会触发十六向视线。原生客户端有时优先显示视线，会暂时打断待机、招手或工作片段。开启系统减少动态效果后，原生播放器可能只显示首帧。悬停时可以主动看到舞步和出门，错误、等待和检查片段则由相应的任务通知触发。

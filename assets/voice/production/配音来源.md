# 大肥鱼的活泼调皮声线

先用 Qwen3-TTS VoiceDesign 按文字设计一位年轻成年女性的动画声音，录制招呼、出游和讨小鱼三句试听。选用的「活泼调皮」参考声长 5.60 秒，保存在 reference.wav。reference.json 记录了官方演示的声音描述、逐字稿和参考文件校验值。[Qwen 项目](https://github.com/QwenLM/Qwen3-TTS) · [官方 VoiceDesign 演示](https://huggingface.co/spaces/Qwen/Qwen3-TTS)

十三段普通话成品均使用同一条参考声音，在本机用 Qwen3-TTS-12Hz-1.7B-Base 重新生成。十二个互动动作和任务完成各有一句整句配音，包含打招呼。制作采用 MLX Audio 和 BF16 权重。后期只调整首尾留白和整段响度，保留原有的音高、呼吸、连读和语速。应用内的单声道 WAV 采用 24 kHz、16 位 PCM，可离线播放。[MLX 模型固定版本](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-Base-bf16/tree/a6eb4f68e4b056f1215157bb696209bc82a6db48) · [MLX Audio](https://github.com/Neywa-Labs/mlx-audio)

## 重新制作

在支持 Metal 的 Apple 芯片 Mac 上安装 Python 3.12、mlx-audio 0.6.8、mlx 0.32.5、NumPy、SciPy 和 FFmpeg。下载上面的 Base 固定版本并保留 speech_tokenizer 子目录。进入本目录运行以下命令。

```sh
python render.py /path/to/Qwen3-TTS-12Hz-1.7B-Base-bf16
```

每句选定的录制参数见 takes.json。句长、响度和校验值见 recordings.json。追加 `--only playful crying` 可以仅录指定台词，`--output` 可将成品写入新目录。

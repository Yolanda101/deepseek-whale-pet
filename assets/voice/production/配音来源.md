# 大肥鱼的清甜声线

这套普通话配音为大肥鱼单独设计。先用 Qwen3-TTS VoiceDesign 生成清甜、圆润的年轻成年女性动画声线，再让 Base 模型参照同一段 6.32 秒的合成样音，为十二个动作及任务完成提示录制独立台词。参考声音可以在本目录的 reference.wav 中试听，原始声音描述、逐字稿和校验值见 reference.json。[Qwen 项目](https://github.com/QwenLM/Qwen3-TTS) · [官方 VoiceDesign 演示](https://huggingface.co/spaces/Qwen/Qwen3-TTS)

问候在 Qwen 的官方演示中用 1.7B Base 生成，其余台词使用同模型经 MLX 转换的 BF16 权重和 MLX Audio 在 Apple 芯片上录制。每一条都由模型完整说出。后期保留连读、呼吸、原始音高和语速，仅修剪首尾并统一响度。应用随附 24 kHz、16 位单声道 PCM WAV，可离线播放。[MLX 模型固定版本](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-Base-bf16/tree/a6eb4f68e4b056f1215157bb696209bc82a6db48) · [MLX Audio](https://github.com/Neywa-Labs/mlx-audio)

## 重新制作

在支持 Metal 的 Apple 芯片 Mac 上安装 Python 3.12、mlx-audio 0.6.8、mlx 0.32.5、NumPy、SciPy 和 FFmpeg。下载上面的 Base 固定版本，保留其 speech_tokenizer 子目录。进入本目录运行以下命令。桌宠日常播放只需成品 WAV 和台词清单。

```sh
python render.py /path/to/Qwen3-TTS-12Hz-1.7B-Base-bf16
```

追加 `--only playful crying` 可单独录指定的台词。`--output` 可把结果写入新目录。问候使用随附的官方原始录音重新裁切与调音。
